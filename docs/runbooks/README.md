# Runbooks

Um runbook por procedimento operacional ou alerta crítico.

Todo alerta que acorda alguém aponta para um runbook daqui. Alerta sem runbook é achado da
auditoria de observabilidade.

| Runbook | Serviço | Alertas cobertos |
|---|---|---|
| [Reset do banco local](reset-banco-local.md) | PostgreSQL local (`db` do Compose) | Nenhum (procedimento manual, destrutivo) |
